# E-Commerce Website
A full-stack e-commerce platform that allows users to browse products, add items to the cart, place orders, and manage purchases.

## Features
- User authentication and authorization
- Product browsing and searching
- Category filtering
- Shopping cart functionality
- Secure checkout process
- Order management
- Responsive design
- Admin product management

## Tech Stack

### Frontend
- React.js
- React Router
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

### Clone Repository
git clone <repository-url>

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm run server
